**Provenance:** locked Farm OS design work from session `01a04f06-bfbe-7b32-bf12-f9834e900244`.
**Rule:** the session ID is provenance only; agents must use this repository document and the repository visual-reference manifests. No agent may depend on chat/session access.

## Product identity

Farm OS is an illustrated agricultural operating system: warm pastoral storytelling + serious farm intelligence + species-specific biology + field-grade usability.
It must be recognisable without the logo and must not collapse into a generic Material, SaaS, fintech, AI-dashboard or CRUD aesthetic.

## Root visual grammar

The locked reference establishes: warm sunlit countryside; layered foreground/midground/background; green hills/pasture; large natural tree framing; barn/silo/farm structures; blue-grey distant landscape; approachable believable livestock; cream/off-white task surfaces; deep agricultural green primary controls; soft rounded geometry; clean operational sans-serif typography; restrained handwritten accent copy; calm, authored composition.

Illustration is identity, not decoration. It is strongest on I1/I2 surfaces and progressively restrained on I3/I4 operational and safety screens.

## Reproducible rendering law

All new visual references and implementations must inherit the same family:
- painterly/editorial digital farm illustration rather than flat corporate vector art;
- soft natural modelling and atmospheric depth rather than glossy 3D;
- believable friendly animals rather than mascots, emoji or clip-art;
- warm cream surfaces and farm-green actions rather than sterile white-card grids;
- natural greens, bark/soil browns, sky blue-grey, muted barn red and warm sunlight accents;
- interfaces placed inside calm contrast zones of the scene;
- species/environment context changes by module while rendering language stays constant.

Forbidden substitutions: default Material styling, generic flat-vector livestock, photoreal cut-outs, 3D mascots, neon, glassmorphism, fintech gradients, cyber-AI dashboards, inconsistent illustration families, emoji animals.

## Intensity classes

- I1 Immersive illustrated: Splash, Login, Account, Onboarding, Farm Setup.
- I2 Illustrated product: Farm Home, species entrances/dashboards, health/pasture/intelligence entrances.
- I3 Operational with illustrated identity: lists, profiles, capture, inventory, finance, reports, settings.
- I4 Clinical/safety: treatment, withdrawal, mortality, biosecurity, destructive confirmations, access loss.

The locked login is the visual-DNA seed, not a universal page layout. A rabbitry, cattle dashboard and finance report must feel like one product while using different scene density.

## Theme inheritance test

For every screen ask: “Could this plausibly have been designed by the same Farm OS illustrator/product designer as the locked countryside login?” If not, it is visual drift.
