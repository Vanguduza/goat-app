## Problem and resulting behavior

Home mixed device utilities and feature lists into its operational content. Search required too much reading. Several modules exposed navigation as plain text. Rabbitry offered a catalogue of actions without a useful visual relationship between breeding dates, nest-box states and cages.

Home now keeps the original Animal Farm context, real attention, summaries, species illustrations and bottom navigation. More contains a compact persona-derived menu: Search, farm tools (including Sync), farm operations, business and insights. Group headings control disclosure. Sync shows the current queue summary as a menu row and runs only through its existing explicit action. The bottom-right gear remains Theme only. Summary and species tiles align; larger text uses stacked summaries and fewer family tiles per row.

Search presents the editable tag/name/ID field first and offers matches after a 220 ms pause. Species, status and identifier tools are optional. Each request includes the active farm and all filters. A changed request immediately hides old rows, cancels the prior job and guards subsequent result/error/busy updates. The Room query applies eligibility before the 50-animal limit; aliases cannot consume that limit or cross the active-farm boundary. Typing prefixes do not flood recent searches. Clear, retry, intentional submit and species destinations retain distinct behavior.

Shared outlined/filled controls and compact rows make navigation visible on Rabbitry, tasks, health, inventory and the affected species dashboards. Commands, clinical warnings, receipts and permissions stay with their native owners. Task filters remain selectable filters; add/edit/done invoke existing callbacks. Back is visible before content on shared operational pages.

Rabbitry groups actions into Breeding, Housing, Animals and Records. Its overview displays actual wave/cage counts and labeled planned mating, kindling and weaning dates, with the planned nest window. Conflicting recorded outcomes stay visible. The selected group survives returning from child navigation. Initial loading completes before the dashboard action groups appear, keeping their tap positions stable.

The cage board displays exact stored cage-to-wave links, capacity and linked-plan counts. Selectable plans share a date scale; nest windows and the current-day marker have a key. The selected wave shows all six milestones with separate planned and recorded evidence. A past date never fills an activity marker. The nest diagram uses the native ready/assigned/in-cage/to-clean graph, including allowed skips and return through cleaning. State controls display counts and filter real boxes. Unknown statuses stay separate.
